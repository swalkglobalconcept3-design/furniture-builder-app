# Furniture Builder App

A small furniture customization app built with HTML, CSS, and JavaScript.

## Features
- Choose furniture type
- Select board material and color
- Set width, height, and depth
- Add custom features like drawers or premium finish
- View instant quotation
- See build instructions and material guidance

## Run locally
Open `index.html` directly in a browser or serve the folder with a local web server.

Example:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Files
- `index.html` — App structure
- `style.css` — Styling and layout
- `script.js` — Furniture logic and quotation calculation
